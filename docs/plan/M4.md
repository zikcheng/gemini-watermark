# M4 — Three-stage detection and orchestration (src/detect.ts)

> **Base fact**: this repository is a faithful TypeScript port of
> [GeminiWatermarkTool](https://github.com/allenk/GeminiWatermarkTool) —
> a C++ tool that removes Gemini's visible image watermark via
> deterministic reverse alpha blending. The C++ source (v0.3.2, commit
> `7c6a99f`, checked out at `$GWT_UPSTREAM_DIR`) is the sole behavioral
> authority; we reproduce its behavior, quirks included, never "improve" it.
>
> **Required upstream reading (in full, before writing code)**:
> `src/core/watermark_engine.cpp` — `detect_one_variant`,
> `detect_watermark`, `remove_watermark`, and the threshold-gate rationale
> comment inside `process_image`; `src/cli/cli_app.cpp` —
> `process_single` (the fallback orchestration) and the surrounding
> flag handling for `--legacy` / `--no-legacy` / `--force` /
> `--force-small` / `--force-large`.

Prerequisite: M3 complete.

## Context

Detection is the **safety gate**: it decides whether an image gets
modified at all, so a user who feeds in a non-watermarked image gets it
back untouched. Upstream runs three weighted stages (spatial NCC 0.50,
gradient NCC 0.30, variance dampening 0.20) with a circuit breaker, a
spatial-rescue rule for busy backgrounds, and a ±3px snap for V2-small
positions; the CLI tries the V2 profile first and falls back to V1.
Reproducing the **decisions** exactly — including the cases upstream
itself misses (`v2-large-2752x1536-hard` must skip) — is the equivalence
bar; scores only need to match the manifest within 2e-3.

This milestone also fixes the library's public API (contract draft below)
**before** any detection code is written, because detection's outputs are
the API's core types. Everything prior (M1–M3) provided the ingredients;
after M4 the package is functionally complete, and M5/M6 are packaging
and proof. Oracle: the manifest + detection-level patches from M0,
rebuilt to full-size images via `test/helpers/reconstruct.ts` — never
feed a bare patch as an image (it changes the geometry).

## Commit 1 — [MUST BE FIRST] API contract freeze

Deliverables: `docs/api-contract.md` + reshaped `src/types.ts` + type
tests. **Creating detect.ts before this commit lands is forbidden.**
Contract draft below; the session may make only two kinds of changes:
corrections verified against upstream behavior (with recorded evidence)
and naming tweaks. No new capabilities.

```ts
// —— Detection layer (the output of detect_one_variant) ——
interface DetectionScores { spatial: number; gradient: number; variance: number }
interface DetectionResult {
  variant: WatermarkVariant; size: WatermarkSize;
  region: Rect;               // post-snap region (formula position when the trust gate fails)
  confidence: number;
  scores: DetectionScores;
  circuitBreaker: boolean;    // breaker path (confidence = spatial×0.5 there)
  internalDetected: boolean;  // the internal 0.35 label; informational, not the gate
}
detectWatermark(image, opts?: {variant?: WatermarkVariant,
  size?: WatermarkSize}): DetectionResult      // single variant, default V2

// —— Gating (pure functions, independently testable) ——
passesThreshold(confidence: number, threshold: number): boolean  // >=
// internal pure functions (exported for tests): spatialCircuitBroken(s),
// spatialRescued(s), fuseConfidence(scores), snapTrusted(spatial)

// —— Orchestration layer ——
type ProcessStatus = 'processed' | 'skipped'
interface ProcessResult {
  status: ProcessStatus; confidence: number;
  variant?: WatermarkVariant; size?: WatermarkSize; region?: Rect;
  attempts: DetectionResult[];   // the gate-detection sequence (V2 [, V1]); excludes internal re-detections
}
processImage(image: ImageBuffer, opts?: {
  mode?: 'remove' | 'add',        // default remove
  threshold?: number,             // default 0.25; gates remove only
  autoFallback?: boolean,         // default true; effective only when variant unspecified
  force?: boolean,                // default false; true = skip the gate (threshold
                                  // ignored, matching upstream — not an error); the
                                  // internal snap detection still runs; no V1 fallback
  variant?: WatermarkVariant,     // explicit = fallback disabled
  size?: WatermarkSize,           // forced-size; upstream quirk as-is
  logoValue?: number,             // default 255
}): ProcessResult
// Semantics: in-place mutation; on 'skipped' the buffer must be byte-identical;
// mode:'add' has no detection concept (upstream add is unconditional; V1 is the
// default, variant:'V2' is the documented TS extension); invalid ImageBuffer
// throws RangeError/TypeError; no 'error' status exists in the library (CLI concept)
```

Sync: the existing `DetectionResult` in `types.ts` (the
`detected: boolean` shape) reshapes per the table (position/blend
unaffected); type tests = lock the public surface with `expectTypeOf`.

## Commit 2 — port detect_one_variant

`src/detect.ts`. Section-by-section against the C++ (functions referenced
in CLAUDE.md), key points:

- ROI computation with four-edge clamping; `snap_pad = 3` for V2 small
- Grayscale → float/255; alpha region: snap mode slides the whole
  template, non-snap mode aligns via out-of-bounds cropping (the
  `alpha_roi` logic)
- Stage 1 NCC → `spatialScore`; adopt the offset only when snapping and
  `spatial ≥ 0.60` (`snapTrusted`); breaker at `spatial < 0.25` →
  return confidence = spatial×0.5
- Stage 2 Sobel-magnitude NCC; Stage 3 variance
  (`ref_h = min(y1, config.logoSize)`, enabled only when `ref_h > 8`,
  scored only when `s_ref > 5.0`)
- Fusion 0.50/0.30/0.20 → clamp [0,1]; rescue takes the max when
  `spatial ≥ 0.30`; `internalDetected = confidence ≥ 0.35`
- Every constant comes from the CLAUDE.md rule-7 list, each annotated with
  its C++ origin

Tests (this commit, CI): the full pure-gate suite at `<` / `==` / `>`
(0.25/0.30/0.35/0.60 + passesThreshold at arbitrary thresholds).
