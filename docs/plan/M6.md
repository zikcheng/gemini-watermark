# M6 — v0.1.0 release preparation (rehearsal, no publish)

> **Base fact**: this repository is a faithful TypeScript port of
> [GeminiWatermarkTool](https://github.com/allenk/GeminiWatermarkTool) —
> a C++ tool that removes Gemini's visible image watermark via
> deterministic reverse alpha blending. The C++ source (v0.3.2, commit
> `7c6a99f`) is the sole behavioral authority.
>
> **Required reading**: no upstream code — this milestone is release
> mechanics only. Inputs: this repo's CHANGELOG conventions, `files`
> whitelist, and the rehearsal script below.

Prerequisite: M5 complete. **No cleanup-type operations in the active
working tree at any point; `npm publish` and `git tag` require explicit
user instruction and are not executed in this milestone.**

## Context

The most common release failure is not broken code — it is a broken
artifact: a tarball missing `dist/`, containing a stale build, or failing
to import in a consumer project. This milestone rehearses the entire
release in a **temporary clone** (never the active working tree) and
proves the tarball works by installing it into throwaway ESM-JS and TS
consumer projects. The actual `npm publish` and `git tag` are
deliberately left to the user — the deliverable here is that when the
user says "publish", it is a checklist execution with zero unknowns.

## Commit 1 — release infrastructure

- `package.json`: `"prepack": "npm run build"`; confirm the `files`
  whitelist
- `CHANGELOG.md` (Keep a Changelog): the 0.1.0 entry — feature list,
  compatibility-matrix summary, the V2-add extension note, upstream
  version mapping (v0.3.2 / `7c6a99f`)
- `docs/release-checklist.md`: the rehearsal steps below + release-day
  steps (publish `--provenance` pending authorization, tag/CHANGELOG
  consistency, post-publish `npm i gemini-watermark@0.1.0` smoke)

## Rehearsal (in a temp directory; execute step by step and record output)

```bash
CANDIDATE_SHA=$(git -C ~/gemini-watermark rev-parse HEAD)   # record it
git clone ~/gemini-watermark /tmp/gw-release && cd /tmp/gw-release
git checkout "$CANDIDATE_SHA"
npm version 0.1.0 --no-git-tag-version    # package.json + lockfile
npm ci && npm run check
npm pack                                   # produces gemini-watermark-0.1.0.tgz
tar -tzf *.tgz                             # verify: only dist/ LICENSE README.md package.json
# consumer smoke (one ESM JS + one TS):
mkdir /tmp/gw-consumer && cd /tmp/gw-consumer && npm init -y
npm i /tmp/gw-release/*.tgz typescript tsx
#  esm.mjs: import { processImage } from 'gemini-watermark' + a sample-patch call
#  main.ts: same, verifying type inference; npx tsc --noEmit && node esm.mjs && npx tsx main.ts
```

The version bump (0.1.0) lands as a proper commit back in the main working
tree.
